# Speaker Splitter

Невеликий десктопний додаток (tkinter) на основі `pyannote.audio`. Приймає посилання на YouTube або власний аудіо/відео файл і зберігає двоканальний `.wav`: один спікер у лівому каналі, інший у правому, на оригінальній часовій шкалі. Коли спікер мовчить, у його каналі тиша.

## Структура

| Файл | Призначення |
|---|---|
| `app.py` | Інтерфейс tkinter, фоновий потік, черга повідомлень |
| `diarizer.py` | Діаризація та збирання стерео (модель вантажиться один раз) |
| `media.py` | Завантаження з YouTube (`yt-dlp`) і конвертація в WAV (`ffmpeg`) |
| `setup.bat` | Встановлення: Python, ffmpeg, автовизначення GPU, `.env` |
| `run.bat` | Запуск (бере `.venv-gpu`, якщо він є, інакше `.venv`) |
| `requirements.txt` / `requirements-gpu.txt` | Залежності для CPU / NVIDIA GPU |

## Встановлення (Windows)

1. Потрібен Python 3.10, 3.11 або 3.12.
2. Створіть токен Hugging Face (read) і прийміть умови доступу до моделей pyannote на тому ж акаунті.
3. Запустіть `setup.bat`. Скрипт перевіряє Python і ffmpeg, визначає NVIDIA GPU (і питає, чи ставити GPU-версію), створює віртуальне середовище та `.env`. Вставте токен у `.env` (`HF_TOKEN=...`).
4. Потрібен **shared**-білд ffmpeg: `winget install -e --id Gyan.FFmpeg.Shared`, після чого відкрийте новий термінал.

GPU-версія ставиться в окреме `.venv-gpu`, тож CPU-варіант лишається як запасний. У вікні програми можна примусово обрати «Тільки CPU».

## Використання

1. Запустіть `run.bat`.
2. Вставте посилання на YouTube **або** оберіть файл (лише одне з двох).
3. Оберіть папку результату (за замовчуванням `output/` поруч із програмою).
4. Натисніть «Старт» і дочекайтеся повідомлення «Готово».
5. У статусі буде видно, який спікер у якому каналі. Кнопка «Відкрити папку» відкриває результат.

Файл називається `<назва>_stereo_speakers.wav`. Якщо такий уже є, додається номер, тому нічого не перезаписується. Частота дискретизації та сама, що в оригіналі.

## Типові проблеми

- **`Could not load libtorchcodec`**: не shared-білд ffmpeg або не збігаються версії torch і torchcodec. Перевірте `ffmpeg -version`, у виводі має бути `--enable-shared`.
- **Не вдалося завантажити модель**: перевірте `HF_TOKEN` і чи прийняті умови доступу до моделей на Hugging Face.
- **Помилка завантаження з YouTube**: оновіть yt-dlp командою `.venv\Scripts\python.exe -m pip install -U yt-dlp` (або `.venv-gpu\...`). YouTube часто змінюється.
- **Не вистачає пам'яті GPU**: програма сама повторить обробку на CPU.
- **Знайдено не двох спікерів**: кількість спікерів зафіксована (`NUM_SPEAKERS = 2` у `diarizer.py`), для інших записів програма поверне помилку.
- Обробка на CPU довгих записів може тривати довго.

Використовуйте лише матеріали, які ви маєте право обробляти, з урахуванням умов YouTube та авторських прав.
