# Speaker Splitter

Невеликий десктопний додаток (tkinter) на основі `pyannote.audio`. Приймає посилання на YouTube або власний аудіо/відео файл і зберігає двоканальний `.wav`: один спікер у лівому каналі, інший у правому, на оригінальній часовій шкалі. Коли спікер мовчить, у його каналі тиша.

## Структура

| Файл                                        | Призначення                                                                                        |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `app.py`                                      | Інтерфейс tkinter, фоновий потік, черга повідомлень                      |
| `diarizer.py`                                 | Діаризація та збирання стерео (модель вантажиться один раз) |
| `media.py`                                    | Завантаження з YouTube (`yt-dlp`) і конвертація в WAV (`ffmpeg`)                |
| `setup.bat`                                   | Встановлення: Python, ffmpeg, автовизначення GPU, `.env`                          |
| `run.bat`                                     | Запуск (бере `.venv-gpu`, якщо він є, інакше `.venv`)                             |
| `requirements.txt` / `requirements-gpu.txt` | Залежності для CPU / NVIDIA GPU                                                                  |

## Встановлення (Windows)

1. Потрібен Python 3.10, 3.11 або 3.12.
2. Створіть токен Hugging Face (read) і прийміть умови доступу до моделей pyannote на тому ж акаунті.
   (див. [Як отримати токен Hugging Face](#як-отримати-токен-hugging-face))
3. Запустіть `setup.bat`. Скрипт перевіряє Python і ffmpeg, визначає NVIDIA GPU (і питає, чи ставити GPU-версію), створює віртуальне середовище та `.env`. Вставте токен у `.env` (`HF_TOKEN=...`).
4. Потрібен **shared**-білд ffmpeg: запустіть команду `winget install -e --id Gyan.FFmpeg.Shared` в PowerShell, після чого відкрийте новий термінал.

GPU-версія ставиться в окреме `.venv-gpu`, тож CPU-варіант лишається як запасний. У вікні програми можна примусово обрати «Тільки CPU».

## Як отримати токен Hugging Face

Модель діаризації завантажується з Hugging Face, а доступ до неї «закритий»: потрібен безкоштовний акаунт, токен і прийняті умови використання. Усе це робиться **на одному й тому самому акаунті**.

### Крок 1. Створіть акаунт (якщо його ще немає)

1. Відкрийте [https://huggingface.co/join](https://huggingface.co/join).
2. Зареєструйтеся (e-mail і пароль) та підтвердіть e-mail за листом, який надійде на пошту. Без підтвердженої пошти доступ до закритих моделей може не працювати.

### Крок 2. Прийміть умови доступу до моделей

Відкрийте **кожне** з цих двох посилань, увійшовши в акаунт, і на кожній сторінці пройдіть те саме:

- [https://huggingface.co/pyannote/speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1)
- [https://huggingface.co/pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0)

На сторінці моделі:

1. Знайдіть блок «You need to agree to share your contact information to access this model».
2. Заповніть поля (зазвичай «Company/university» і «Website»). Можна вказати будь-що, наприклад `Personal` і `-`; це лише форма для авторів моделі.
3. Натисніть кнопку **Agree and access repository**.
4. Після цього блок зникне, а вгорі сторінки не буде повідомлення про обмежений доступ. Доступ зазвичай надається одразу.

Якщо хоч одну з двох моделей пропустити, програма не зможе завантажити пайплайн і покаже помилку «Не вдалося завантажити модель».

### Крок 3. Створіть токен доступу (read)

1. Відкрийте [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (також: аватар у правому верхньому куті → **Settings** → **Access Tokens**).
2. Натисніть **Create new token**.
3. Оберіть тип **Read** (це найпростіший варіант і його достатньо). Якщо інтерфейс показує вкладки *Fine-grained / Read / Write*, обирайте саме **Read**.
4. Вкажіть будь-яку назву, наприклад `speaker-splitter`, і натисніть **Create token**.
5. Скопіюйте токен (він починається з `hf_`). **Повний токен показується лише один раз**: збережіть його одразу. Якщо загубите, просто створіть новий, а старий видаліть.

### Крок 4. Вставте токен у `.env`

- Під час першого запуску `setup.bat` (Windows) або `setup.sh` (macOS) скрипт сам створить `.env` з `.env.example` і відкриє його в текстовому редакторі. Замініть значення так:

  ```
  HF_TOKEN=hf_ваш_токен_тут
  ```

  Без пробілів навколо `=` та без лапок. Збережіть файл.
- Якщо `.env` уже існує, відкрийте його з папки програми й зробіть те саме.

Не публікуйте токен і не додавайте `.env` до репозиторію (він уже виключений у `.gitignore`).

> Інтерфейс Hugging Face іноді змінюється, тому назви кнопок можуть трохи відрізнятися, але логіка та сама: прийняти умови двох моделей і створити токен типу Read.

## Використання

1. Запустіть `run.bat`.
2. Вставте посилання на YouTube **або** оберіть файл (лише одне з двох).
3. Оберіть папку результату (за замовчуванням `output/` поруч із програмою).
4. Натисніть «Старт» і дочекайтеся повідомлення «Готово».
5. У статусі буде видно, який спікер у якому каналі. Кнопка «Відкрити папку» відкриває результат.

Файл називається `<назва>_stereo_speakers.wav`. Якщо такий уже є, додається номер, тому нічого не перезаписується. Частота дискретизації та сама, що в оригіналі.

## Типові проблеми

- **`Could not load libtorchcodec`**: не shared-білд ffmpeg або не збігаються версії torch і torchcodec. Перевірте `ffmpeg -version`, у виводі має бути `--enable-shared`.
- **Не вдалося завантажити модель**: перевірте `HF_TOKEN` і чи прийняті умови доступу до моделей на Hugging Face.
- **Помилка завантаження з YouTube**: оновіть yt-dlp командою `.venv\Scripts\python.exe -m pip install -U yt-dlp` (або `.venv-gpu\...`). YouTube часто змінюється.
- **Не вистачає пам'яті GPU**: програма сама повторить обробку на CPU.
- **Знайдено не двох спікерів**: кількість спікерів зафіксована (`NUM_SPEAKERS = 2` у `diarizer.py`), для інших записів програма поверне помилку.
- Обробка на CPU довгих записів може тривати довго.

Використовуйте лише матеріали, які ви маєте право обробляти, з урахуванням умов YouTube та авторських прав.
